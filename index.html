Instalar Despesas no iPhone

Adicione o aplicativo à Tela de Início:

  1. Abra esta página no Safari, caso esteja em outro navegador.
  2. Toque no botão Compartilhar (quadrado com seta para cima). Se não aparecer, abra o menu do navegador.
  3. Selecione Adicionar à Tela de Início (em algumas versões, dentro de “Mais”).
  4. Confirme em Adicionar.

Depois, abra o Despesas pelo ícone criado. Os dados ficam neste dispositivo. Não apague os dados do navegador antes de fazer backup.
